## Changes made by this project

The scripts in `scripts/` select and rename columns, join records, normalize the
schema, derive driver career and season tables, and generate event and standings
tables. In particular, `scripts/drivers.py` combines the championship and driver
datasets to produce `drivers.csv`, `driver_career_stats.csv`, and
`driver_seasons.csv`. Transformed outputs retain the applicable terms of the
data used to create them; conversion to CSV or SQL does not remove those terms.
Some CSV files are supplied directly rather than generated by these scripts.

## Use and redistribution

The project's Apache 2.0 grant permits loading, transforming, and using its
contributions in an internal SQL Server test environment for training and
practice. No separate permission from this project is required for that use.
The upstream data terms above still apply.

When redistributing Apache-licensed material, include [LICENSE](LICENSE), retain
applicable attribution and copyright notices, include the relevant contents of
[NOTICE](NOTICE), and prominently identify modified files as required by the
license. Keep this data notice with redistributed CSV bundles so recipients can
identify the upstream sources and terms.

Data added independently from another provider, such as Jolpica-F1, is subject to
that provider's own terms. This repository does not license those additions.
